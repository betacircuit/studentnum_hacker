# studentnum_hacker

전정 25학번 이름 명단에서 이름 → 학번 후보, 학번 → 이름 후보를 검색합니다.
`index.html`을 직접 열거나 `python -m http.server 8000`으로 실행합니다.

- 박준후 `2025-19418`은 사용자가 확인한 전체 학번으로 `확인됨`을 표시합니다.
- 확인되지 않은 연결은 검색 방향에 따라 `이 학번일 가능성이 높음` 또는 `이 이름일 가능성이 높음`을 표시합니다.
- 같은 끝 3자리의 후보가 여러 개면 모두 표시하며, 학번 후보 수와 이름 후보 수를 안내합니다. 후보 간 우선순위나 수치 확률은 정하지 않습니다.
- 학번 자료가 없는 이름도 이름으로 검색할 수 있습니다. 화면 아래 `학번 정보가 없는 이름`에서 전체 목록을 확인합니다.
- 별명·부분 이름을 공식 이름에 자동으로 연결하지 않습니다.

## 데이터

`data/cohort.json`은 사용자가 제공한 이름 명단을 정리한 것입니다. 괄호 안 분반과 장식 표기를 제거했고, 성이 뒤에 적힌 명확한 표기만 이름 순서로 정리했습니다.
사진에 등장한 이름은 앞선 잠정 제외보다 우선하므로 강승범·허준혁을 포함합니다. 편성주는 제외했습니다.
출결 PDF와 지정좌석 CSV에서 이름과 끝 3자리를 대조한 결과는 `data/lookup_source.json`에 저장합니다.
PDF에서 학과가 다르게 표기된 이름도 사용자 제공 25학번 명단에 있으면 포함하고 원래 학과 표기를 유지합니다.
좌석 위치는 원본 CSV의 번호가 있는 줄과 열 위치입니다.

`confirmed`는 사용자가 직접 확인한 연결, `probable`은 끝 3자리 일치 후보, `unknown`은 학번 후보가 없는 이름입니다.
이름 명단 확인은 해당 학생의 전체 학번 확인을 의미하지 않습니다.

```sh
python scripts/build_data.py
node --test
```

후속 확인 결과는 `data/lookup_source.json`의 학번과 상태를 수정하고 생성 명령을 다시 실행합니다.
가상 CSV와 `scripts/make_sample_data.py`는 과거 데모 자료이며 현재 조회 데이터 생성에는 사용하지 않습니다.
