# studentnum_hacker

전정 25학번 이름 명단에서 이름 → 학번 후보, 학번 → 이름 후보를 검색합니다.
`index.html`을 직접 열거나 `python -m http.server 8000`으로 실행합니다.

## 화면과 조작

어두운 배경, 금색 숫자 다이얼, 청색 이름 다이얼과 기하학 로고로 구성했습니다. 검색 전에는 로고·다이얼·작은 입력창만 표시합니다.

- 이름은 다이얼 아래 입력창에서 입력하고 자동완성 후보를 선택합니다. 이름 다이얼은 결과 애니메이션만 보여줍니다. 자동완성은 방향키와 Enter로도 선택할 수 있습니다.
- 학번은 직접 입력하거나 끝 네 숫자의 위·아래 버튼, 스크롤, 위·아래 방향키, 드래그로 조절합니다. `2025-1` 접두부는 고정입니다. 전체 학번, 뒤 네 자리, 뒤 세 자리 검색을 지원합니다.
- 전환 애니메이션은 150–220ms이며 마지막에 작은 걸림과 반동을 줍니다. 연속 조작 시 앞선 애니메이션을 취소하고 마지막 입력을 표시합니다. 기기의 동작 줄이기 설정을 따릅니다.
- 박준후 `2025-19418`은 사용자가 확인한 학번이며 청색 상태 점을 표시합니다. 끝자리 일치 후보는 금색, 학번 정보가 없는 이름은 붉은색 상태 점을 표시합니다. 추정 문구와 충돌 후보 수는 보조 읽기 영역에 제공하고 학번 후보 버튼에도 미확정을 표시합니다.
- 여러 학번 후보는 `2025-1?XXX`와 후보 버튼으로 표시합니다. 모르는 학번은 `2025-1????`이며, 등록되지 않은 이름은 이름 다이얼에도 `?`를 표시합니다. 학번 검색에서 여러 이름이 나오면 작은 좌·우 버튼으로 전환합니다. 후보에 수치 확률이나 우선순위를 부여하지 않습니다.
- 경고 아이콘은 붉은 정보 제안 창을 엽니다. `정보 수정 요청` 버튼도 같은 양식을 열며 이름·학번·학부·제안 내용을 수정할 수 있습니다. 요청 버튼은 GitHub 이슈 작성 화면을 새 창으로 열고, 사용자가 그 화면에서 최종 제출합니다.

외부 화면·폰트 의존성 없이 정적 파일로 실행됩니다. 등록되지 않은 이름을 검색해도 데이터에 자동 등록하지 않습니다.

## 데이터

`data/cohort.json`은 사용자가 제공한 이름 명단을 정리한 것입니다. 괄호 안 분반과 장식 표기를 제거했고, 성이 뒤에 적힌 명확한 표기만 이름 순서로 정리했습니다.
사진에 등장한 이름은 앞선 잠정 제외보다 우선하므로 강승범·허준혁을 포함합니다. 편성주는 제외했습니다.
사용자 정정에 따라 `Sassy 승경`은 `서승경`, `규원`은 `홍규원`으로 저장했습니다. 두 이름의 학번은 PDF 끝자리와 CSV의 일치 후보이며 아직 `probable`입니다. 다른 별명·부분 이름은 임의로 공식 이름에 연결하지 않습니다.
출결 PDF와 지정좌석 CSV에서 이름과 끝 3자리를 대조한 결과는 `data/lookup_source.json`에 저장합니다.
PDF에서 학과가 다르게 표기된 이름도 사용자 제공 25학번 명단에 있으면 포함하고 원래 학과 표기를 유지합니다.
좌석 위치는 원본 CSV의 번호가 있는 줄과 열 위치입니다.

`confirmed`는 사용자가 직접 확인한 연결, `probable`은 끝 3자리 일치 후보, `unknown`은 학번 후보가 없는 이름입니다.
이름 명단 확인은 해당 학생의 전체 학번 확인을 의미하지 않습니다.

```sh
python scripts/build_data.py
node --test
```

후속 확인 결과는 `data/lookup_source.json`의 학번과 상태를 수정하고 생성 명령을 다시 실행합니다.
가상 CSV와 `scripts/make_sample_data.py`는 과거 데모 자료이며 현재 조회 데이터 생성에는 사용하지 않습니다.
